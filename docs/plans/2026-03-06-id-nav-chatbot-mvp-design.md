# ID-NAV Chatbot MVP Design

## 문서 정보
- 작성일: 2026-03-06
- 대상: id-nav-chatbot MVP
- 목표 파일럿 시작일: 2026-05-30
- 우선순위: 운영 효율 우선
- 플랫폼: iOS + Android 동시

## 1. 배경과 목표
본 MVP는 실내 위치 인프라가 부족한 주차장/복합상업시설에서 사용자 길찾기와 운영 효율을 개선하기 위한 최소 제품을 구축한다.  
핵심은 `출입구 QR 앵커 + 휴대폰 센서 기반 PDR`로 위치를 추정하고, 목적지까지 최적 경로를 실시간 안내하는 것이다.

### 대상 공간
- 지하주차장
- 복합상업시설

### 성공 기준(KPI)
- 목적지 도착 성공률
- 경로 재탐색 빈도
- 주차 탐색 시간 감소율
- 위치 오차(중앙값)
- 세션 자동 종료 정확도

## 2. 범위
### 포함
- 고객용 모바일 웹앱
  - QR 스캔으로 세션 시작
  - 센서 기반 위치 추정(PDR)
  - 목적지 선택 및 최적 경로 안내
  - 경로 이탈 감지/재탐색
  - 오차 상승 시 앵커 스캔 요청(수동 스캔형)
- 관리자 웹
  - 시설/구역 상태 모니터링
  - 주요 이벤트 대시보드(이탈/재탐색/스캔)
  - KPI 리포트
- 서버/데이터
  - 멀티시설(tenant) 구조
  - 세션/경로/도착/주차 위치 이벤트 수집
  - 모델 고도화용 학습 데이터 파이프라인(익명)

### 제외
- 개인식별정보 기반 로그인/마케팅 기능
- BLE/IMU 전용 고정밀 인프라 확장
- AprilTag 자동 인식 기반 상시 트래킹

## 3. 핵심 설계
### 3.1 위치 추정
1. 출입구 QR 스캔으로 앵커 좌표와 세션 시작.
2. 가속도/자이로/자력 기반 보행 추정(PDR)으로 이동 거리/방향 계산.
3. 실내 맵 그래프에 스냅하여 비정상 궤적 제거(맵 매칭).
4. 오차 상승 시 사용자에게 내부 QR 재스캔 요청.
5. 재스캔 시 좌표 재보정 후 안내 지속.

### 3.2 경로 안내
1. 사용자가 목적지 선택.
2. 맵 그래프 기반 최적 경로 계산(A* 계열).
3. 이동 중 위치 업데이트로 이탈 감지.
4. 이탈 시 재탐색 후 경로 갱신.

### 3.3 세션 종료 규칙
`50m 단일 기준`이 아니라 아래 복합 규칙 적용:
- 기본 거리 감지: 건물 경계 밖 50m 이상
- 시간 조건: 이탈 상태 30~60초 연속
- 히스테리시스: 종료 60~70m, 재진입 40~50m
- 신호 품질 필터: GPS 정확도 저하 시 종료 판단 보류

## 4. 데이터 정책
### 4.1 개인정보 원칙
- 개인식별정보(이름/전화번호/이메일/광고ID) 미수집
- 익명 `session_id` 기반 저장

### 4.2 수집 항목
- 이동 경로
- 선택 도착지
- 주차 위치
- 도착/이탈/재탐색 이벤트
- 센서 요약 피처

### 4.3 보관/활용
- 원시 센서 데이터: 90일 보관
- 파일럿 종료 후 적정 보관 기간 재산정
- 수집 데이터는 AI 이동 모델 고도화에 사용

## 5. 앵커 전략
- MVP 1차: 내부 앵커는 QR만 사용
- 정책: 기본 수동 스캔형
- 조건부 요청: 오차 상승 예상 시 태깅 요청
- 향후: 정밀도 이슈 발생 시 AprilTag(AT) 도입 검토

## 6. 아키텍처 개요
- 클라이언트: 모바일 웹앱(iOS/Android), 관리자 웹
- 백엔드: API 서버, 실시간 이벤트 처리, 배치 집계
- 저장소: 맵/앵커 메타, 세션 이벤트, 집계 리포트
- 테넌트 분리: 시설별 데이터/권한 격리

## 7. 에러 처리
- 센서 품질 저하: 정확도 경고 + 재스캔 유도
- GPS 품질 불량: 경계 이탈 종료 판단 지연
- 스캔 실패: 재시도 가이드 + 인근 앵커 대체 안내
- 경로 계산 실패: 직전 안정 좌표 기준 재시도

## 8. 테스트 전략
- 기능 테스트
  - QR 시작/재스캔/세션 종료
  - 목적지 선택/경로 안내/이탈 재탐색
- 현장 테스트
  - 주차장/복합시설 각각 실제 동선 검증
  - 위치 오차, 도착 성공률, 재탐색 빈도 측정
- 운영 테스트
  - 관리자 KPI 집계 정확도
  - 이벤트 누락/중복 확인

## 9. 리스크와 대응
- 리스크: 기기/센서 편차로 위치 오차 확대
  - 대응: 맵 매칭 + 조건부 재스캔 + 기기군별 보정
- 리스크: GPS 오차로 오종료
  - 대응: 거리+시간+히스테리시스+신호품질 결합
- 리스크: 사용자 스캔 피로
  - 대응: 요청 빈도 제한(쿨다운), 꼭 필요할 때만 요청

## 10. 결정 사항 요약
- 파일럿 공간: 지하주차장 + 복합상업시설
- 우선순위: 운영 효율 우선
- 플랫폼: iOS + Android 동시
- 기술: QR 기반 + 센서 PDR + 맵 매칭
- 앵커: 내부 QR 수동 스캔(AT는 추후 검토)
- 데이터: PII 미수집, 원시 센서 90일 보관
- 일정: 2026-05-30 파일럿 시작 목표
