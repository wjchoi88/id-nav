# ID-NAV MVP 사용자 요구사항 (2026-03-07)

## 1. QR 스캔 플로우

### 첫 번째 스캔
- QR 스캔 시 서비스 페이지 접속
- 사용자가 도착지 선택
- QR 위치(현재 앵커) → 도착지까지 최적 경로를 **입면도 + 평면도**에 표시

### 두 번째 이후 스캔 (세션 유지 중)
- 처음 스캔 위치 → 현재 QR 위치: **지나온 경로** 표시
- 현재 QR 위치 → 도착지: **최적 경로** 표시

## 2. 최적 경로 정의

- **일반 사용자**: 최단 거리 (계단 포함, 엘리베이터 제외)
- **교통약자** (토글 ON): 엘리베이터 경유 경로 우선 안내
- 교통약자 여부는 세션 내 유지

## 3. 관리자 페이지

### 인증
- 관리자 로그인 필수
- 기본 계정: `admin` / `admin1234`

### 필수 메뉴
- QR 생성 (HMAC 서명 포함 URL 생성)
- QR 등록 (앵커 위치 정보 입력)
- QR 삭제

### 추가 메뉴 (MVP 범위 내 자체 판단)
- 앵커 목록 조회 및 편집
- 세션/방문 통계 (KPI 대시보드)
- 도착지(목적지) 목록 관리

## 4. 유저 페이지 구성 요소

| 요소 | 설명 |
|------|------|
| QR 스캔 카메라 | 브라우저 카메라 API 기반 QR 인식 |
| 입면도 이미지 | 층간 이동 경로 표시 (B1↔B2) |
| 평면도 이미지 | 현재 층 경로 오버레이 |
| 교통약자 토글 | ON: 엘리베이터 경유, OFF: 최단 거리 |
| 도착지 선택 목록 | 3개 분류: 승차위치 / 편의시설 / 기타 |

## 5. 비기능 요구사항

- 앱 설치 불필요 (웹 브라우저 기반)
- iOS / Android 동시 대응
- PII 미수집 (익명 session_id 기반)
- QR URL: `https://id-nav.databuilder.co.kr/scan/:anchorCode`

## 6. 파일럿 대상

- **샛강역** (서울 9호선 + 신림선 환승역)
- B1: 9호선 승강장, 개찰구, 출구, 편의시설
- B2: 신림선 승강장
- 앵커 12개 (B1: 8개, B2: 4개) — 좌표는 현장 실측 후 확정
